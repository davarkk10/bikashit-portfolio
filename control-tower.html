Why Phase 5 model metrics differ
This is a separately retrained release-checkpoint logistic-regression model with 23 features, seed 20260926 and a different temporal split. Its PR-AUC 0.3516, ROC-AUC 0.7078, recall 34.99%, 1,137 false negatives and 3.613× top-decile lift are reported separately from the earlier release model's PR-AUC 0.475. Selection followed Brier gate → PR-AUC → lower false-negative count, never accuracy alone.
Real bugs found and fixed
  • Non-deterministic feature-column ordering silently broke a persisted scaler; fixed with ordered tuples and verified through a full rerun.
  • psql literal-quoting substitution failed in single-command mode; switched to script mode and rechecked with an SQL-injection probe.
  • Migration replay attempted to shrink a PostgreSQL view; added migration tracking and verified on live and fresh databases.
Component status ledger
  • Implemented and tested: canonical contract and leakage gate; release ML pipeline; threshold and priority policy; 5-endpoint FastAPI/Pydantic API; action catalogue; 16-table/9-view PostgreSQL layer; 6 structurally validated n8n workflows.
  • Built with gaps noted: Docker Compose parsed but images could not be pulled; Power BI specs and live CSV exist but the native .pbix page needs Desktop; second-company onboarding is documented but not externally tested.
  • Future enhancement: allocation-complete and dispatch automation checkpoints.

Scope and reproducibility
NorthEast HealthLink Distributors Pvt. Ltd. is entirely hypothetical. All orders, customers, products and outcomes were generated by a seeded simulation (seed 20260915). Scale: 99,433 total order records—95,912 completed, 3,026 cancelled and 495 test—plus 301,757 order lines, 1,462,000 inventory rows, 500 products, 200 customers, 25 suppliers, 6 carriers and 4 warehouses. The original build references ./run_pipeline.sh; that pipeline and its raw exports are not included in this public web repository, so the training and reconciliation claims cannot be independently rerun from this page. The original build did not create a native .pbix, use NLEM medicine names or OSM routes, run the DataCo/Olist benchmark, or record a demo video. The portfolio screenshots show this HTML prototype. A separate saved Power BI build pack uses different data and model results and is not mixed into this web case.
