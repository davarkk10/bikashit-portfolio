# Bikashit Baruah portfolio

This repository contains the same 13 website files as the public Netlify portfolio build of September 28, 2026. The site content, interactions, and outbound links are unchanged. The portrait is visually preserved in a smaller WebP file for reliable GitHub delivery.

## Publish with GitHub Pages

1. Push these files to the root of a GitHub repository on the `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)` and save.
4. Open the Pages URL displayed there after deployment completes.

`index.html` is the homepage. `control-tower.html` is Case 01's interactive page. Case 02 remains linked to its Power BI report; Case 03 links to the live Power BI report and the `procureai/` case page. Case 04 (`olist/`) is a PostgreSQL analysis of the real public Olist e-commerce dataset, with SQL, saved results and a case page. `.nojekyll` tells Pages to serve the static files directly. No account-specific GitHub URL or custom domain is assumed.
